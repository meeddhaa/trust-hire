# Setup notes

## Firebase

Project: **trusthire-bdapps** — https://console.firebase.google.com/project/trusthire-bdapps

Already done (via CLI):
- Project created, Android app registered (`lib/firebase_options.dart`,
  `android/app/google-services.json` generated by `flutterfire configure`)
- Firestore database created (`nam5`) with baseline security rules deployed
  (`firestore.rules` — see comments there for the server-writes-only design)
- `storage.rules` written, ready to deploy once Storage is enabled (below)

### Manual steps still required (console-only, no CLI path)

1. **Enable Firebase Storage** — the default bucket's region can only be
   picked through the console's "Get Started" flow, not the CLI/API:
   https://console.firebase.google.com/project/trusthire-bdapps/storage
   Then deploy the already-written rules:
   ```
   firebase deploy --project trusthire-bdapps --only storage
   ```

2. **Enable Auth providers** — Email/Password and Google:
   https://console.firebase.google.com/project/trusthire-bdapps/authentication/providers
   - Email/Password: toggle on, no further config.
   - Google: toggle on. For Google Sign-In to work on Android you also need
     to register a SHA-1 (debug) and later SHA-1/SHA-256 (release) certificate
     fingerprint on the Android app in Project Settings. Get the debug one with:
     ```
     cd android && ./gradlew signingReport
     ```
     then paste the SHA-1 under Project Settings → Your apps → trusthire (Android).

Once both are done, re-run `flutter pub get` if `google-services.json` gets
re-downloaded, and the app can authenticate end-to-end.

## Fonts

Fraunces and Manrope (both OFL-licensed) are bundled as variable-font assets
under `assets/fonts/` rather than fetched via `google_fonts` at runtime, so
the app never depends on a network call just to render text — relevant for
a judged demo on unpredictable venue wifi. License: `assets/fonts/OFL.txt`.

## GitHub

No `gh` CLI is available in this environment. Once you're ready to push:
```
gh repo create trusthire --private --source=. --remote=origin
git push -u origin main
```
or create the repo manually on GitHub and `git remote add origin <url>`.
